Wichtige Information: Diese Tabelle zeigt Ihnen exakt, wie die Excel-Spalten beim Import den Datenbankfeldern zugeordnet werden. Die Excel-Datei muss genau diese Spaltenreihenfolge einhalten, damit die Daten korrekt importiert werden. Die erste Zeile sollte die Spaltenüberschriften enthalten und wird beim Import übersprungen.

Importprozess:

  1. Excel-Datei hochladen
  2. Erste Zeile (Header) wird übersprungen
  3. Ab Zeile 2: Jede Zeile wird als ein Patientenprofil verarbeitet
  4. Leere Profilnummer (Spalte C) beendet den Import
  5. Bestehende Profile werden überschrieben, neue werden erstellt

Wichtige Hinweise für Administratoren

  • Die Profilnummer (Spalte C) ist der Primärschlüssel - sie muss eindeutig sein!
  • Leere Zellen werden als leere Strings in der Datenbank gespeichert (nicht als NULL)
  • Die HiO-Hinweise (AM & AN) sind die Felder spare_col1 und spare_col2
  • Spalten AO bis AT enthalten "Übergabe RD" Daten und werden bewusst übersprungen
  • Der Import beginnt bei Zeile 2 - Zeile 1 sollte die Spaltenüberschriften enthalten
  • Der Import stoppt, wenn eine leere Profilnummer (Spalte C) gefunden wird
  • Bestehende Profile mit gleicher Profilnummer werden komplett überschrieben
  • Die Datei muss als .xlsx Format vorliegen
  • Sehr lange Texte werden automatisch gekürzt, um in die Datenbankfelder zu passen
  • Fehlermeldungen bei einzelnen Zeilen brechen den gesamten Import nicht ab
